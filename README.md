# iFruit Concept Website

A responsive fan-made iFruit smartphone launch concept built with React, Vite and Tailwind CSS.

## Launch information
The concept lists **January 1, 2027** as the planned release. This is fictional/conceptual and is not an official announcement by Rockstar Games or a device manufacturer.

## Website features
- Cinematic homepage and concept phone renders
- Single iFruit phone section with a planned release date
- Interactive newswire stories and informational/footer panels
- Functional in-page links and responsive mobile navigation
- Footer inspired by the reference layout, with iFruit branding
- No checkout, video player, email collection, or real-order capability

## Development
```sh
npm install
npm run dev
npm run build
```
