# iFruit fan-concept storefront

React + Tailwind / Vite storefront.

## Add the product film

The hero and Watch Video button expect an MP4 at `public/ifruit-ad.mp4`. The site autoplays it **muted**, inline, and on a loop, and offers sound and playback controls in the Watch Video modal. If the file is not present, the cinematic gradient hero remains visible.

To publish the supplied product video, upload the file as `public/ifruit-ad.mp4` on the `main` branch. Vercel automatically rebuilds the linked project.

## Run locally

```sh
npm install
npm run dev
```

## Notes

Product prices, editorial stories, signups, checkout, and account UI are illustrative. Payment processing, authentication, and email collection are not configured. The project is an unofficial fan concept and not affiliated with Rockstar Games or Take-Two Interactive.
